Relationship Viewer

Switch between Child → Parent, Parent → Child, Base Object Lineage, and Base Object Diagram. The diagram view shows a simplified upward/downward hierarchy from one base object and caps height/depth at 10 levels.
Tree graph scope: The generated hierarchy ignores non-createable reference fields, audit fields (CreatedById, LastModifiedById), ownership fields (OwnerId), references targeting User, polymorphic references, and objects without a usable REST describe resource. Polymorphic relationships are excluded only from hierarchy ordering and should be resolved separately during the migration's deferred lookup pass. In the ObjectHierarchy sheet, RecordLookupCount counts relationships used by this graph, RecordLookups lists them, and OtherLookups lists external or deferred relationships with the reason. Migration analytics provide dependency waves, parent/child impact, foundation status, cycle-aware phases, deferred-lookup counts, parallel batches, and risk ratings.
